# Parity with DrawnUI for .NET

Upstream baseline: `DrawnUi/DrawnUi.Net`, branch `Cells`, commit `d7e9fab2` (2026-09-29). Later C# changes that were followed are named by their commit in the rows.

One row per upstream feature. Rows are edited in place when the status changes, never appended twice.
Status: `ported`, `partial`, `skipped`, `changed` (kept, but behaves differently; say how).

| Host contract (surface, frame loop, pointer, assets) | partial | Every platform from one host contract: Windows, Linux, macOS, iOS, Android and the browser. Desktop GL (winit + glutin; Windows, Linux on X11 / Wayland with the window icon from the app's `icon.ico`; where the driver ignores vsync the host spaces frames one refresh apart, as the C# OpenTK host in its Dynamic mode). macOS and iOS: Metal only (a CAMetalLayer on the winit view, paced by the display, no display link; iOS up to 120 Hz on ProMotion screens), touches as the pointer on iOS, the safe area from the view, no GPU work while in the background. Pointer events carry their arrival time on the frame clock; `PointerKind::Cancel`. Wheel: `App::wheel` in notches, answered at once; the browser keeps the page from scrolling only when a control used it. Images: `Host::fetch_image` / `App::image`, decoded by the host off the frame thread (desktop: worker threads; browser: `createImageBitmap` in a worker). Frames on demand; a timer or a sleeping animator makes the host wake at its time (desktop `WaitUntil`, browser `setTimeout`) without frames in between. Keyboard: DOM `code` names on both hosts (winit KeyCode names, Super = Meta; Backspace is Backspace, forward delete is Delete), modifiers, repeat, typed text (desktop: key text + IME commit; browser: window listeners + a hidden textarea for soft keyboards, IMEs and paste), blur. All mouse buttons, hover and leave, context menu. Cursor requests. Clipboard (browser; desktop Windows and Linux: X11 selections). Asset channel for controls (`Tree::assets`: SVG, Lottie, shader sources). Browser: `DrawnUi.start({ resolveAsset })` lets the page answer every file load (images in the decode worker included) with its own address, e.g. a `blob:` url; `DrawnUi.start({ fonts })` registers fonts from the page before the first frame (never the default font), as C# loads an uploaded font at run time. No multi-touch. |
| Control tree | changed | Arena with generational ids; handlers get the control, the app state and a context instead of capturing controls. | Measure / Arrange contract | partial | Margin, size requests, Minimum / Maximum requests, LockRatio, Fill ratios, layout options, `CalculateLayout` Center rule with one-sided margins and `RoundCenterAlignment` (a centered control takes the odd free pixel; constant `ROUND_CENTER_ALIGNMENT` in `layout.rs`, on as upstream), re-measure on a Fill axis when arranged into another box, a measure is never larger than its constraint (a Minimum still wins), a zero constraint measures empty. | `UseCache`: Operations, OperationsFull, Image | changed | Image caches on whole pixels, nearest blit. | `UseCache`: ImageDoubleBuffered, ImageComposite | changed | ImageDoubleBuffered as C# on every native host, desktop, Android and iOS (`SkiaControl.Cache.cs:840-1218`): a CPU bitmap made by 2 to 4 bake workers (`src/bakes.rs`); the last bitmap shows meanwhile, unstretched at the control's place; until the first bitmap is back every frame draws DrawPlaceholder (background color or rgba(128,128,128,32); C# 23b52ad0); one bake per control is out, the latest content follows; the same content at a new size or scale is made in the frame (TrySyncRebuildStaleSize). Browser: made in the frame as Image (C# CanUseCacheDoubleBuffering is false on the web), keeping the last one while a new one cannot be made. ImageComposite as React: the surface is kept; when only children changed (the child a change came through is taken from the invalidation walk) those children, where they were and are, and every sibling overlapping that are erased and drawn again; the control's own change, a new layout, size, scale or effects margin (a glow that moved sides, C# 97683f19 EffectsMarginMismatch), or a control that is not a plain layout draws everything. `Tree::last_composite_record` / `Cx::last_composite_record` (React LastCompositeRecord). A change deeper than a child (a card in an uncached stack) is drawn again by its area (drawnui-cross 6m, C# 766d2f75): the control's rect with its effects margin, through its transform, as drawn before and now, through the content offsets and transforms on the way; the areas are erased and the child they are in is drawn clipped to them; a visual effect or a backdrop on the way draws the child whole; a new layout draws everything, so do more than `MAX_COMPOSITE_AREAS` (16) areas or areas over `MAX_COMPOSITE_SHARE` (half) of the control; `CompositeRecord::areas` / `changed`. Changed: a DRAW on a child re-records only that child (React: Update is InvalidateMeasure, a full record); a transform on the way is mapped into the area (C# draws the child whole, and its whole-child redraw is not clipped). |

| Canvas RenderingMode | changed | `Ui::rendering_mode(RenderingModeType)`, read by the host once before the first frame.
